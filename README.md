# AutoCapture

กด **F9** → แคปหน้าต่างที่อยู่หน้าสุด → ฝังรูปลง Validation Report (Word) ทีละจุด

## ติดตั้ง

```
pip install python-docx pillow mss keyboard pywin32
```

## โครงไฟล์

เรียกใช้ที่ `main.py` ไฟล์เดียว ที่เหลือแยกตามหน้าที่

| ไฟล์ | หน้าที่ |
|---|---|
| `main.py` | ทางเข้าเดียว — กัน 2 หน้าต่าง แล้วเปิด GUI |
| `capture.py` | logic แคปหน้าจอ + ย่อ/เก็บภาพลง `captures/` |
| `ui_word.py` | หน้าต่างหลัก — รายการจุด, hotkey, ปุ่มต่างๆ |
| `ui_picker.py` | หน้าต่างเลือกรูปจากโฟลเดอร์ (แทรกรูปที่มีอยู่แล้ว) |
| `pic_target.py` | โหมด `<pic>` — วางรูปแทน marker |
| `word_target.py` | โหมดตารางขั้นตอน — วางรูปในช่อง Actual Result |
| `config.py` | ตั้งค่า — แก้ไฟล์นี้ไฟล์เดียว |

## ใช้งาน

```
python main.py
```

1. กด "เปลี่ยนเอกสาร" เลือกไฟล์ Word แล้วเลือกตารางจาก dropdown
2. เปิดค้างไว้ ทำงานอื่นได้ตามปกติ กด **F9** เพื่อแคปลงจุดที่ไฮไลต์อยู่ แล้วเลื่อนไปจุดถัดไปเอง
3. ไม่อยากได้ทั้งหน้าต่าง กด **Shift+F9** แล้วลากกรอบเลือกเฉพาะส่วนที่ต้องการ (Esc = ยกเลิก)
   ปุ่มนี้ต่อ modifier จากปุ่มหลักเอง เปลี่ยนปุ่มหลักเป็น F3 ปุ่มนี้จะกลายเป็น Shift+F3
4. คลิกจุดใดก็ได้ในรายการเพื่อกลับไปแก้

โปรแกรมดูโครงเอกสารเอง รองรับ 2 แบบ:

- **โหมด `<pic>`** — เอกสารมี `<pic>` วางไว้ตรงจุดที่ต้องการรูป โปรแกรมวางรูปแทนทีละจุด
  (1 จุด = 1 รูป วางซ้ำ = แทนที่รูปเดิม อยากได้หลายรูปให้ใส่ `<pic>` หลายอัน)
- **โหมดตารางขั้นตอน** — ตารางมีคอลัมน์ Actual Result และช่อง No. เป็นตัวเลข

### ปุ่มในหน้าต่าง

| ปุ่ม | ทำอะไร |
|---|---|
| คืนค่า `<pic>` | ถอดรูปที่จุดนี้ออก คืนเป็น `<pic>` เหมือนเดิม (โหมด `<pic>`) |
| นำเข้าด้วยรูปภาพ | เลือกรูปที่ถ่ายไว้แล้วจากโฟลเดอร์มาใส่ — คลิกจุดทางซ้าย คลิกรูปทางขวา |
| เปิด Word | เปิดไฟล์ผลลัพธ์ใน Word |

หน้าต่าง "นำเข้าด้วยรูปภาพ" เปลี่ยนตารางได้ในตัว และบอกว่ารูปไหนถูกใช้ไปแล้วโดย
**เทียบเนื้อรูปกับรูปที่ฝังอยู่ในเอกสารจริง** จึงบอกได้แม้รูปถูกใส่ไว้ตั้งแต่รอบก่อนๆ

## ผลลัพธ์

- `output/<ชื่อไฟล์>_capture.docx` — ไฟล์ที่โปรแกรมเขียน **ต้นฉบับไม่เคยถูกแตะ**
- `captures/` — ภาพต้นฉบับ .png สำรองไว้เผื่อไฟล์ Word เสีย
- `settings.json` — จำไฟล์ / ตาราง / ปุ่มลัดที่ใช้ล่าสุด

## ตั้งค่า

ปุ่มลัดเปลี่ยนได้จากช่อง "ปุ่มลัด" ในหน้าต่าง (บันทึกลง `settings.json`)
ที่เหลือแก้ใน `config.py`:

| ค่า | ความหมาย |
|---|---|
| `DEFAULT_HOTKEY` | ปุ่มเริ่มต้น — ถ้า F9 ชนกับโปรแกรมอื่น ใช้ `"ctrl+alt+f9"` |
| `IMAGE_DIR` | โฟลเดอร์ภาพสำรอง |
| `WORD_IMAGE_WIDTH` | pixel ที่เก็บใน .png ยิ่งมากยิ่งคม แต่ `.docx` ใหญ่ขึ้น |
| `WORD_IMAGE_CM` | ความกว้าง fallback ถ้าอ่านความกว้างคอลัมน์จริงไม่ได้ |
| `WORD_OUTPUT_DIR` | ที่เก็บไฟล์ผลลัพธ์ |

## ข้อควรรู้

- **แคปหน้าต่างที่ active ตอนกด** ไม่ใช่ทั้งจอ — ต้องคลิกให้หน้าต่างนั้นอยู่หน้าสุดก่อนกด F9
- **ปิด Word ให้สนิทก่อนกด F9** ถ้าเปิดไฟล์ผลลัพธ์ค้างไว้จะเขียนไม่ได้
  (ภาพยังเก็บใน `captures/` ครบ ไม่หาย)
- **อย่าเปิดโปรแกรม 2 หน้าต่างพร้อมกัน** — hotkey เป็นแบบทั้งเครื่อง เปิดซ้อนกันจะแคปซ้ำจริง
- **ไฟล์ทั้งหมดอยู่ในโฟลเดอร์โปรแกรมเสมอ** ไม่ว่าจะเปิดจากที่ไหน (shortcut, Task Scheduler)
  เพราะยึด `BASE_DIR` ใน `config.py` ไม่ใช่ current directory

## ถ้าขึ้นข้อความสีแดง

ภาพ **ไม่หาย** เก็บอยู่ใน `captures/` เสมอ แก้ต้นเหตุแล้วกดใหม่ได้เลย

| ข้อความ | สาเหตุ | วิธีแก้ |
|---|---|---|
| `Word เปิดไฟล์ค้างอยู่` | เปิดไฟล์ผลลัพธ์ค้างไว้ | ปิด Word แล้วกดใหม่ |
| `ไม่พบจุดรูปลำดับที่ N` | เอกสารถูกแก้จนจุดไม่ตรง | กด "เปลี่ยนเอกสาร" เลือกใหม่ |
| `(OSError)` | ดิสก์เต็ม / ไฟล์ถูก sync ล็อก | เคลียร์พื้นที่ หรือหยุด OneDrive sync ชั่วคราว |
